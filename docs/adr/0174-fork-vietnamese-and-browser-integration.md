# ADR-0174：fork 复用上游翻译与容器入口

状态：已采纳。日期：2026-11-18。

## 背景

上游已有完整英文、i18next 语义键与统一服务端消息；旧 fork 按中文原句维护独立词表。
两套入口并存会重复翻译，也无法覆盖上游新增消息。fork 还需要保留可操作验证页的浏览器镜像。

## 决策

- 使用上游翻译调用和英文资源，越南文进入同一 `resources/locales/vi/`，移除旧词表及其运行入口。
- 越南文缺键先取英文，再取中文，作为 ADR-0156 在本 fork 的语言回落补充。
- 保留旧浏览器语言选择，用户在新入口明确保存后按上游同步设置运行。
- browser 是 runtime 的可选目标，继承同一 UID/GID、数据卷迁移及降权入口。
- 普通镜像仍为默认目标，browser 的独立手动构建和验收不替换上游的标准发行流程。

## 结果

更新上游时只维护越南文资源与明确的浏览器扩展，不再合并两套前端翻译实现。
翻译、容器构建、镜像发布与真实 NAS 验收分别记录；源码同步不表示容器已经更新。
用法见 [界面语言](../LOCALIZATION.md) 和 [浏览器镜像](../DOCKER_BROWSER.md)。
