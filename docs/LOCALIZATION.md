# 界面语言

本 fork 使用上游的 i18next、语义键、英文资源与服务端 `message_code`，支持简体中文、English 和 Tiếng Việt。
「自动」优先匹配浏览器语言，再看服务端系统语言；没有对应译文时使用英文。设置入口在「外观与导航」。
切换语言会重新载入页面，沿用上游行为；提交表单后再切换，以免丢失未保存输入。

## 越南文资源

译文位于 `resources/locales/vi/`，与 `en/` 共用十个命名空间；`cli` 只供命令行使用，不打入前端包。
新增功能先沿用上游中文和英文，再按英文含义补充越南文。已存在且含义相符的 fork 译文继续复用。
越南文缺键时先取英文，再取中文；作品名、人物名、标签、用户输入、路径和来源资料不参与翻译。

保留 `{{name}}`、`{{count, number}}` 等占位、命令、文件名、URL 和产品名称。
数量使用数字参数，由 i18next 按越南语格式显示，不预先把数字格式化成字符串。
后端模板、登录、首次设置和 CLI 使用同一份资源，不另建字符串替换层。

本次补充的新词条包含从英文生成的翻译草稿，已对齐插值并修订主要技术术语；
完整观感和场景用词仍以真实预览为准。

## 旧版选择

旧 fork 的 `peach.locale.v1` 在浏览器启动时转入现有设置缓存，保留同一缓存中的其他偏好。
升级后服务端默认的「自动」不覆盖这份旧选择。在新语言入口成功保存后结束兼容处理，
后续按上游同步设置运行。存储不可写时仍尝试读取旧选择，不改写作品资料或 ledger 真相字段。

## 核对与维护

`frontend/test/i18n.test.ts` 覆盖越南文键完整性、占位、数量格式、英文回落、旧选择迁移和存储失败。
后端语言识别、设置保存和模板渲染分别由对应 Python 行为测试覆盖。
正式验证使用当前工作树的 `scripts/test.sh` 或 `scripts/test.ps1`；预览和确认遵循 `UI_PREVIEW.md`。
