# 界面语言

首次设置、登录页和错误页提供「界面语言」选择；进入应用后，在设置的「外观与导航」中修改。可选 English、Tiếng Việt 与简体中文。切换时更新文案和文档语言，不刷新页面，不清空正在填写的表单。

语言偏好保存在当前浏览器的 `peach.locale.v1`。另一浏览器或设备独立选择；同一浏览器的标签页同步变化。未选择、存量无效或存储不可读时沿用中文。存储写入失败时显示原因并保留原选择。

语言入口用于首次设置、登录、错误页、浏览偏好、导航、馆藏、搜索、播放列表、资料复核、关注管理、配置、任务与播放器。加载占位、可访问名称和已登记的系统消息使用同一词表。片名、人物名、标签原文、用户输入、文件路径、来源摘录、诊断 JSON 和 API 值保持原样；未登记的外部错误原因也保留原文。

## 维护译文

词表位于 `frontend/src/i18n/catalog.ts`，每项以中文原文为键，依次提供英文和越南文。占位符名称在三种语言中一致，值只插入一次，不递归解释。

React 界面通过 `frontend/src/react/i18n.ts` 的 `useTranslation()` 订阅语言变化，在明确的界面文案处调用返回的翻译函数。无插值参数的运行时文案可匹配已登记系统模板，原始资料字段不经过此函数。缓存的列定义等结构把翻译函数纳入依赖，切换后更新文字并保留当前交互状态。

请求失败由 `requestErrorSource` 保留原始原因，`requestErrorMessage` 按当前界面语言显示。`ApiError.sourceMessage`、状态码和原始响应体独立保存；切换语言时不把已有译文再次当成服务端原因解析。表单请求的 `useAction` 保存原文并订阅语言变化。

系统消息使用 `translateSystem` 或 `useSystemTranslation`，只匹配 `system-messages.ts` 中完整登记的模板。路径、名称和计数作为占位值保留；未知消息仍显示原文。设置行、提示和处理进度接在这层，不把模板匹配用于片名、标签、来源摘录或任意 DOM 文本。

公共控件间接使用的固定词条登记在 `supplemental-messages.ts`，动态回执登记在 `runtime-messages.ts` 并纳入系统模板。匹配优先采用固定文字更长的完整模板，避免带系统盘说明的容量被较短模板截走。占位值保持原样，不递归翻译名称或路径。

后端 API 的表单校验、任务进度、下载、字幕与复核消息登记在 `backend-messages.ts`，由同一系统模板层显示。请求错误也匹配这些完整模板；原始响应体与原因独立保留。固定词条先直接查表，仅含占位符的模板进入正则匹配，未知诊断仍显示原文。CLI 帮助与未进入网页的内部校验信息不据此改写。

日期和数字使用 `i18n/format.ts`，日期按界面语言与浏览者所在时区显示。表单值、API 参数、排序键、文件路径和持久化标识不随显示语言变化。

## 覆盖核对

运行 `npm --prefix frontend run check:i18n` 查看源码文案清单，追加 `-- --json` 输出文件、行号、字符串种类与接入状态。清单解析 TypeScript、JavaScript 和 JSX，不把注释、模块路径、类型和对象键算成界面文案。静态 JSX 正文与可访问属性属于可见文案；其它运行时字符串须结合调用方区分界面、协议值与馆藏内容。`-- --check` 对未接入的静态可见文案、缺少词表的翻译调用和语法错误返回失败。

源码清单不代替运行验收。后端返回的原因、任务进度、日期、数量、弹层与播放器控件须另做行为验证；作品名、人物名、路径、用户输入和来源原文保留原值。浏览器检查需同时验证语言切换、当前输入保留、辅助技术名称及桌面和窄屏布局。

`frontend/e2e/localization.test.ts` 使用独立合成馆藏，检查 31 个路由的英文、越南文及桌面、窄屏布局，并验证实际语言选择器、刷新后的语言偏好、作品详情与播放器设置。可见正文、提示属性和可访问名称中的中文触发失败；仅按路由扣除夹具中明确列出的原始馆藏字段，诊断代码块保留原始 JSON。同一语言和视口复用浏览器会话，各路由仍整页加载；这些结果不代替其它路由、弹层和有数据状态的组件验收。

遗留壳在 `frontend/src/i18n/shell.ts` 接入：`setShellText` 和 `setShellAttribute` 明确标记界面文字，切换时只更新这些标记。不要对整页文本、服务端数据或用户输入作字串替换。属性已被路由改成其他用途时，不恢复为启动文案。

翻译使用现有 React、React Aria、BoardUI 与浏览器存储，不新增运行时依赖。新增界面文案同时补两份译文，行为验证仍经 `scripts/test.sh` 或 `scripts/test.ps1`。
